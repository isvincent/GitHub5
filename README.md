# GitHub 網址百寶箱 🐙

這個互動網頁會讀取試算表，列出 GitHub 網址，讓學生瀏覽和搜尋。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 單頁互動網頁（首頁） |
| `github.csv` | 網址資料（Excel 另存 CSV） |

## 試算表格式

| A 欄 | B 欄 | C 欄 | D 欄 |
|---|---|---|---|
| 序號 | 分類（可留空） | **超連結名稱** | **超連結網址** |

- 網頁使用 **C 欄當名稱**、**D 欄當網址**。第一列標題與網址不正確的列會被略過。
- B 欄有內容時，會自動變成「分類」篩選按鈕。
- 網頁支援 UTF-8 與 Excel 預設的 Big5 編碼 CSV。
- 網頁依序讀取 `github.csv` → `data.csv` → `links.csv`，找不到時改讀同名的 `.xlsx`。

## 更新網址

1. 用 Excel 編輯 `github.csv`，存檔時保留 CSV 格式。
2. 把檔案上傳到 GitHub 儲存庫，覆蓋舊檔。
3. 重新整理網頁，就會看到新內容。

## 開啟 GitHub Pages

儲存庫 **Settings → Pages → Branch: `main` / root → Save**，約 1 分鐘後就能用
`https://<帳號>.github.io/<儲存庫名稱>/` 開啟網頁。

> 直接在電腦上雙擊 `index.html` 時，瀏覽器會擋住讀檔，網頁因此無法自動讀取試算表。這時可以把 CSV 檔拖曳進網頁。

## 網頁功能

- 🔍 即時搜尋並標示關鍵字（按 `/` 可快速搜尋）
- 🗂️ 依分類篩選，也能用名稱或點擊次數排序
- ❤️ 收藏網址，並可只看收藏
- 🎲 隨機探索：輪盤音效加彩帶特效
- 🧱／📜 切換卡片模式或清單模式
- 🔠 調整字級（A－／A＋）
- 🔊 音效由瀏覽器即時合成，可以關閉
- 📋 一鍵複製網址
